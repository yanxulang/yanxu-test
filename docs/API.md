# 言试 API

本文说明稳定行为。完整签名、类成员和协议成员见编译器生成的[API_REFERENCE.md](API_REFERENCE.md)。

## 限制与错误

`默认限制()`返回深比较深度 64、节点 100000、套件测试 4096、夹具 256 和每类钩子 256。`复制值受限`与`深差异受限`允许为单次操作设置更小预算。

`错误详情(错误)`返回：

```text
代码 消息 源代码 类别 位置 踪迹
```

所有言试错误代码以`YANSHI_TEST_`开头。`应当抛错代码`比较代码，不比较消息。

## 断言

| API | 行为 |
| --- | --- |
| `断言/失败` | 条件断言与显式失败 |
| `相等/不相等` | 运行时普通相等 |
| `应为空/应不为空` | 支持空、空文、空列、空典和空字节串 |
| `深差异/深相等` | 递归比较列、典和字节串，返回路径化差异 |
| `近似相等` | 数值绝对容差比较，拒绝负容差 |
| `应含/应匹配` | 文、列、典包含和正则匹配 |
| `类型断言/符合` | 类型名或调用方谓词 |
| `应当抛错*` | 返回捕获的结构化错误供后续检查 |

## 数据驱动

`表格测试(名称, 各行, 测试法)`逐行调用测试法；行典可用`名称`覆盖默认编号。`参数化测试`把每组参数列放入统一行结构。二者返回总数、通过数和逐项结果；首次失败抛稳定错误。

## 套件与夹具

`套件(名称)`返回`测试套件`。注册入口为`测试前/测试后/每项前/每项后/夹具/测试`，名称必须为 1 至 256 字符且不可重复。

每个测试得到独立`测试上下文`。夹具惰性创建、单项内复用，并按注册逆序清理。测试、后置钩子和清理的多个错误会依次保留，不会因首个错误跳过后续清理。

`尝试运行()`返回：

```text
名称 总数 通过 失败 跳过 生命周期失败 成功 结果 生命周期错误
```

`测试前`失败时测试标记跳过，`测试后`仍执行。`运行()`在结构化结果不成功时抛`YANSHI_TEST_SUITE`。

## 临时目录与环境

`建临时目录(基础目录)`创建唯一子目录。`合并()`只接受非空正斜线相对路径，拒绝绝对路径、反斜线和任何`..`段。`清理()`可重复调用，`是否清理()`公开状态。

`隔离环境(典)`与`隔离系统环境(名称列)`提供显式覆盖视图。`设置/删除/恢复`不会修改进程环境。

## Mock、Spy 与时钟

`Mock(时钟)`支持固定返回、返回队列、错误队列和自定义实现。`调用(参数列)`记录参数、结果或错误及时间；`函数()`返回绑定调用法。可用`调用次数/各调用/第次/被调用于/清空`检查。

`Spy(原函数, 时钟)`始终调用原函数并记录同样结构。`虚拟时钟(起始毫秒)`直接返回言时虚拟时钟，可同时注入业务和替身。

## 快照

`快照库(路径, 更新)`读取单一 JSON 典。更新模式创建或替换命名值并立即保存；验证模式用深差异检查。调用方须在隔离测试目录中使用，并自行授予文件权限。

## HTTP Mock

`HTTPMock`支持精确地址、正则地址、永久响应、一次响应和 JSON 响应。每次匹配或未匹配请求都会进入`各请求()`；言访路径保留方法、地址、首部、字节正文、超时、响应上限、请求编号和上下文。

- `请求(...)`与`传输()`保留 0.1 兼容入口；
- `言访传输()`返回正式`言访.自定义传输`对象；
- 文字响应编码为 UTF-8，空响应编码为空字节串，字节响应原样保留；
- 其他正文类型抛`YANSHI_TEST_HTTP_BODY`；
- 未匹配路由抛`YANSHI_TEST_HTTP_UNMATCHED`。

## 数据库事务

`测试事务(连接, 操作)`适配只提供`开始事务/回滚`的简单假连接。`数据库测试事务(连接, 操作)`使用言库托管事务和`完成后回滚(真)`，成功和失败回调都不提交，且回滚时不运行提交后钩子。

数据库事务只覆盖该连接内的数据库操作，不回滚文件、消息、网络或其他连接上的副作用。

## 仓储契约

`仓储协议`定义`重置/创建/读取/更新/删除/全部`。现有仓储可直接实现协议，或用`函数仓储适配器`包装六个回调。

`验证仓储契约(仓储, 初始, 变化, 主键)`在重置后的隔离仓储上验证：

1. 创建返回非空主键；
2. 创建后可读取相同记录；
3. 局部更新保留主键和其他字段；
4. 列出只含更新记录；
5. 首次删除返回真；
6. 删除后读取为空；
7. 重复删除返回假且最终列表为空。

无论验证成功或失败都会再次调用`重置()`。不得对生产仓储执行该函数。
