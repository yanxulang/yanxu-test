# 从 0.1 迁移到 1.0

## 工具链与依赖

将最低言序升级到 1.1.12，重新解析并提交锁文件。言试 1.0 直接依赖言据 1.2、言时 1.0、言访 1.0 和言库 1.0；顶层项目不应继续锁定这些库的开发分支。

## 错误判断

把基于中文消息的判断改为`错误详情()`或`应当抛错代码()`。原有错误消息仍保持可读，但不再是兼容契约。

## 套件结果

`尝试运行()`新增`通过/跳过/生命周期失败/成功/生命周期错误`。每项结果新增`跳过`，失败项包含首错误和完整`错误列`。`运行()`失败代码为`YANSHI_TEST_SUITE`。

套件、测试和夹具名称现在必须非空且不超过 256 字符；重复注册会立即失败。超出测试、夹具或钩子上限也会在注册时失败。

## 临时目录

空基础路径、非目录基础路径、绝对子路径、反斜线、空段和任何`..`段都会被拒绝。原来使用`../`访问临时根外资源的测试必须改用显式独立夹具。

## HTTP Mock

旧`HTTPMock.请求()`和`传输()`继续存在。接入言访客户端时改用：

```yanxu
客户端.使用传输（HTTP.言访传输（））；
```

路由响应正文应为文字、字节串或空。言访请求记录现在包含完整请求快照，而不只有方法、地址、首部和正文。

## 数据库

`测试事务()`继续适配简单假连接。真实言库连接应改用`数据库测试事务()`，它通过`完成后回滚(真)`保留托管事务的超时、取消、保存点和诊断语义。

## 仓储

将现有仓储包装为`函数仓储适配器`，或直接实现`仓储协议`。确认`重置()`只影响隔离测试数据后，调用`验证仓储契约()`统一验证 CRUD 行为。
