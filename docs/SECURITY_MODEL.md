# 安全模型

## 受信边界

测试法、钩子、夹具工厂与清理法、Mock 实现、Spy 原函数、仓储回调和数据库连接均由调用方提供，拥有顶层测试进程已有权限。言试不把不受信代码变成沙箱。

## 资源耗尽

深复制和深比较对深度与节点计数；套件对测试、夹具和钩子计数；名称与仓储输入有长度上限。Mock、Spy、HTTP 请求和快照记录仍会随使用量增长，调用方不得用它们收集无界生产流量。

## 文件系统

临时目录拒绝空根、非目录根、绝对子路径、反斜线、空段和`..`。清理只删除创建出的唯一子目录并可幂等调用。

路径检查不是符号链接沙箱。若攻击者可在测试根中替换路径或符号链接，应使用操作系统隔离的临时根并限制并发写者。快照路径由调用方直接提供，也必须位于隔离目录。

## 数据泄露

Mock/Spy 调用记录、HTTP 请求快照、快照 JSON 和仓储样本不会自动脱敏。不要记录认证首部、Cookie、令牌、密码、个人信息或数据库凭据。言试错误尽量不嵌入完整值；底层回调错误仍可能包含调用方消息。

## 网络

HTTP Mock 的言访适配器声明`真实网络 = 假`且不调用标准网络传输。它不能验证 DNS、TLS、证书、连接超时或分块传输；这些边界应在隔离的本地集成环境中验证。

## 数据库与仓储

`数据库测试事务`依赖驱动正确实现回滚。事务外副作用、其他连接和数据库不支持事务的操作不受保护。

`验证仓储契约`会在开始和结束调用`重置()`。只允许传入专用测试仓储；对生产仓储调用属于破坏性误用。
